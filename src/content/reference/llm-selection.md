## 一、决策树：先问"数据要不要私有化"

选模型第一步不是"哪个最强"，而是：

```
数据是否必须私有化？
├─ Yes → 预算足？自研训练 : 开源模型部署
└─ No  → 需要领域专精？微调(LoRA) : 直接调 API
```

**四方案月成本量级**（粗估）：

| 方案 | 月成本 | 数据安全 | 维护量 | 适用阶段 |
|------|--------|---------|--------|---------|
| 纯 API | $100–10K | 数据出域 | 极低 | 起步，最快验证 MVP |
| 微调（LoRA） | $500–5K | 数据出域训练 | 中 | 成长，需要领域专精 |
| 开源部署 | $1K–10K | 完全私有 | 高 | 成熟，数据敏感 |
| 自研训练 | $50K+ | 完全私有 | 极高 | 核心壁垒 |

**三阶段路线**：起步纯 API → 成长 API+RAG+微调 → 成熟混合（通用走 API / 敏感走开源 / 核心自研）。

## 二、EIA 实测：20 条评估集上的真实对比

这是我在 EIA 项目中做的真实选型测试。在 20 条离线评估集（查询型/分析型/边界型三类）上对三个候选模型进行了对比：

| 维度 | DeepSeek-V4 | GPT-4o | Claude Sonnet 4 |
|------|:--:|:--:|:--:|
| SQL 生成准确率 | 85% | 88% | 87% |
| 中文报告流畅度 | ★★★★★ | ★★★☆☆ | ★★★★★ |
| 中文零售术语理解 | 好（"客单价"准确） | 中（偏英文直译） | 好 |
| 单次分析成本 | **¥0.04** | ¥0.60 | ¥0.80 |
| 月成本（100 次/天） | **¥120** | ¥1,800 | ¥2,400 |
| Function Calling 稳定性 | 偶尔超时 | 稳定 | 稳定 |
| API 兼容性 | OpenAI 格式 | 原生 | 原生 |

**结论**：GPT-4o 的 SQL 准确率仅高 3%，但成本高 15 倍。对于每天 100+ 次调用的 B 端场景，15 倍的成本差意味着月费从 ¥120 变成 ¥1,800。

V4 更新后的成本更加悬殊：DeepSeek 单次分析 ¥0.03，GPT-4o ¥0.98——**29 倍**。年成本差 ¥8,500（~¥300 vs ~¥8,800）。

> **我为什么选 DeepSeek**：不是"GPT-4o 更强所以选它"，而是"DeepSeek 差 3% 精度、省 15 倍成本，ROI 更优"。我用 Prompt 优化和 RAG 增强来弥补那 3% 的准确率差距。详见 [决策案例 D02](/cases/decision-cases/)。

## 五、六个关键考量因素

选型不是只看榜单，这六个维度都要过一遍：

**1. 推理能力** — 复杂业务规则理解需要强推理（Opus 级），简单问答分类抽取用轻量模型即可（V4 Flash 级）。

**2. 上下文窗口** — 长文档分析 1M 已普及（Claude 全系、Gemini 2M），短对话单轮任务 128K 足够。

**3. 工具调用（Function Calling）** — Agent 场景必须支持。不确认的，先跑一个"模型能不能稳定返回结构化工具调用"的小测试。EIA 实测 DeepSeek 偶尔超时，GPT-4o 稳定——但超时可用重试解决，不值得为稳定性多付 15 倍。

**4. 成本（最容易被低估）** — 输出 token 通常比输入贵 2–6 倍，啰嗦的模型比它的输入价看起来更烧钱。EIA 的典型分析每次消耗 24,100 Token（输入 14,550 + 输出 9,550），用 DeepSeek 约 ¥0.03/次，用 GPT-4o 约 ¥0.98/次。

**5. 数据安全** — 企业敏感数据走私有化部署（DeepSeek MIT 开源 / Qwen），通用场景走 API 但注意数据出域条款。

**6. 推理力度（reasoning_effort）** — 同一模型按"想多久"分档：Claude low~max、GPT none~max、DeepSeek Non-think / Think High / Think Max。简单任务用低档压成本、复杂任务上高档——这是和价格、上下文并列的第三个旋钮。
