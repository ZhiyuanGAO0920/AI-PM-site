> 这是 EIA 项目里最贵的一次「学费」。它印证了七原则里的两条：**成本是一级约束**、**局部降级**。

## 现象

用户问了一个边界问题，Agent 进入「生成 → 检查 → 不通过 → 重新生成」的循环，反复重试了 **8 次**才退出。单次对话消耗 **50 万 Tokens**，成本约 **¥0.5**（正常 **¥0.05**）——单次请求成本暴涨 **10 倍**。

## 根因

Reflection Agent 的质量标准设置过高。当 LLM 生成的回答在「格式完美度」上不达标时，Reflection 持续打回重试。而边界问题的回答天然难以「完美」，于是陷入死循环。

本质是：**把「软性偏好」当成了「硬性门槛」**。

## 修复

1. **设上限**：最大重试次数 = 3。
2. **分等级**：区分「硬性条件」（必须满足）和「软性条件」（建议满足）。硬性才打回，软性放行。
3. **自动降级**：第 3 次重试仍不通过，直接降级为「直出」（把当前最好的一版给用户，并标注「未通过质检」）。

## 教训

> **AI 系统的成本失控，通常不是单次贵，而是循环贵。**

任何循环 / 重试逻辑都必须有上限：**Max Retries + Circuit Breaker（熔断）**。AI PM 需要像设计分布式系统一样设计 Agent：设超时、设上限、设降级。这一条后来写进了 EIA 的七原则（成本一级约束 + 局部降级）。

<div class="callout warn">
<strong>给 AI PM 的 checklist</strong>：你设计的任何「自动重试 / 自动反思 / 多 Agent 协作」流程，先问自己三个问题——上限是多少？超时是多少？失败后降级到哪？
</div>
