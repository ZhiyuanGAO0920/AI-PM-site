Case 02 · 个人级

AI 求职 Agent · 在线可体验

零依赖、四维加权评分、Honesty Rule 禁止虚构——可以直接在网站上体验。

核心设计

  • 四维加权评分：技能 35% · 经历 30% · 行业 15% · 成长 10%
  • Honesty Rule：禁止虚构任何经历、技能、数据、量化指标
  • Human-in-the-loop：绝不自动投递，所有决策由人确认
  • 服务端确定性重算：覆盖模型输出的算术

技术架构

  • 零依赖：Node.js 原生，无 npm install
  • 参数化评分：权重和阈值可配置
  • 输入安全：Prompt 注入防护 + Origin 校验
  • 画像持久化：线上 localStorage · 本地文件
线上示例模式开箱即用 粘贴 JD 文字即可体验 真实评分需本地后端
求职 Agent 是零依赖的个人级 AI 工具。四维加权评分——技能、经历、行业、成长各自打分按权重加权。Honesty Rule 禁止虚构任何经历。Human-in-the-loop 绝不自动投递。线上版可以直接体验示例模式——粘贴 JD 文字就能看到评分结果。
